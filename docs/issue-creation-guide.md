# 📝 Issue Creation Guide

We welcome community contributions beyond code! 🎉

If you discover a bug, identify a missing feature, notice documentation improvements, or have an idea to enhance the project, feel free to create an issue.

## 🌟 Who Can Create Issues?
Everyone is welcome to create issues, including:

- 🐞 Bug reports
- ✨ Feature requests
- 📚 Documentation improvements
- ♿ Accessibility enhancements
- 🎨 UI/UX suggestions
- ⚡ Performance optimizations
- 🔒 Security improvements (please report sensitive vulnerabilities privately)

## 📋 Before Creating an Issue
Please ensure that you:

- 🔍 Search existing issues to avoid duplicates.
- 📖 Read the project documentation.
- 🧪 Verify that the issue still exists on the latest version.
- 📝 Use the appropriate issue template.

## 📝 How to Create a Good Issue
A good issue should include:

### Title
Write a short and descriptive title.

*Example:*
> Add dark mode support for the dashboard

### Description
Include:

- What is the problem?
- Why is it important?
- Steps to reproduce (for bugs)
- Expected behavior
- Screenshots (if applicable)
- Suggested solution (optional)

## 💡 Good Issue Examples
- **🐞 Bug**: The leaderboard page crashes when there are no contributors.
- **✨ Feature**: Add GitHub login authentication.
- **📚 Documentation**: Update the README with Docker installation instructions.
- **🎨 Enhancement**: Improve mobile responsiveness for the navigation bar.

## 🚫 Avoid Creating Issues For
- Duplicate reports
- Personal support requests
- Questions unrelated to the project
- Incomplete or vague descriptions
- Multiple unrelated problems in one issue

## 🎯 Want to Work on an Issue?
If you'd like to contribute by solving an issue, simply comment:

```text
/assign
```
Please wait until a maintainer assigns the issue before starting work.

## 🏆 Issue Contributions Matter
Creating high-quality issues is also a valuable contribution to the project. Well-written issues help improve the project and make it easier for others to contribute.

We appreciate contributors who:

- 🐞 Report reproducible bugs
- 💡 Suggest meaningful features
- 📚 Improve documentation
- 🎨 Recommend UI/UX enhancements
- 🔍 Identify performance or security improvements

## ❤️ Thank You!
Every contribution—whether it's code, documentation, testing, or creating high-quality issues—helps make this project better.

Happy Contributing! 🚀
